# 边缘截图（Edge Shot）

一款独立的 Android 截图工具：**截屏 / 选区 / 长截图 / 贴图 / 复制**。
纯原生实现（不带 WebView），安装包只有 4 MB 出头，点开就到截图界面。

## 功能

- **点图标 / 快捷设置磁贴 / 应用快捷方式** 三种入口，都是「截屏 → 拉选区」
- 选区：整屏压暗、八手柄调整、尺寸标签；**默认不预选全屏**
- 工具条六个动作：**保存**（相册 `Pictures/边缘截图`）、**贴图**、**长截图**、**复制**、**粘贴**、**取消**
- **贴图**：把截图钉在屏幕上，可拖动 / 把手缩放 / 双指捏合 / 双击关闭 / 单击弹工具条（替换、复制、保存、关闭）
- **长截图**：MediaProjection 连续抓帧 + 用户自己滑动拼接；右上角小窗实时缩略图；结果预览页带整图缩略条；
  拒绝录屏授权时自动降级为「无障碍慢速截屏」
- **静默截屏**走无障碍服务（只申请截屏 / 手势，不读窗口内容）

## 操作方法

### 开始截图（三种入口）

1. **点桌面图标**，直接进入截屏；
2. 下拉通知栏 / 控制中心点「**截图**」磁贴（列表里没有就在编辑界面拖上去）；
3. **长按桌面图标 → 截图**（应用快捷方式）。

> 点磁贴后通知栏会自动收起，不会出现在截图里。

### 选区与工具条

进界面后整屏压暗，**自己拖出要截的范围**（默认不选，点一下也不会自动全选），
拖八个角上的手柄可以微调，旁边会显示选区尺寸。拉好之后旁边出现一排按钮：

| 按钮 | 作用 |
|---|---|
| 保存 | 存进系统相册 `Pictures/边缘截图` |
| 复制 | 放进剪贴板（别的应用也能粘） |
| 粘贴 | 用剪贴板里的内容替换当前截图（图片或文字都行） |
| 贴图 | 钉在屏幕上当参考 |
| 长截图 | 只截你选中的这一条区域，往下滚着拼成长图 |
| 取消 | 退出 |

### 贴图（类似 Snipaste）

- 拖动移动、**拖右下角的把手缩放**（也可以双指捏合）、双击关闭、单击弹出小工具条：**替换 / 复制 / 保存 / 关闭**。
- 缩放后的大小会记住，下次贴图还是那么大。
- 「替换」会用**剪贴板里的内容**换掉当前贴图（图片或文字都行，文字会画成一张纸条）。
- 贴图是悬浮窗，**盖在所有页面最上层**（需要「显示在其他应用上层」权限）；点一下就提到最前面。

### 长截图（自己滑）

- 点「长截图」→ 系统问一次「是否允许截取屏幕」→ 选**整个屏幕** → 开始。
- 之后**你自己滑动屏幕**，滑多快都行，程序在后面一帧一帧接着拼（不用慢慢等它滚）。
- **停手约半秒**，右上角会出现一个小窗，里面有**已经拼出来的缩略图**，还有「完成 / 取消」两个按钮；
  继续滑它就自动藏起来。通知里也一直是展开就能看到的缩略图。
- 完成后弹预览页：可以上下滚着看，**右上角有一条整图缩略条**，小框标着你正在看的位置，
  在缩略条上点一下（或拖一下）就跳到长图的对应位置。
- 最多拼到 14000 像素高；滑动过程中随时点「取消」就作废。

## 装完要做的一次性设置

1. 打开 App 会提示开无障碍服务（设置 → 无障碍 → 边缘截图）；Android 13+ 还要在「应用信息」
   右上角菜单里允许「受限设置」
2. 贴图需要「显示在其他应用上层」（第一次点贴图会跳系统设置）
3. 想把「截图」放进下拉快捷设置：编辑快捷设置 → 找「截图」磁贴拖进去
4. 保存到系统相册走 MediaStore，Android 10 及以上**不需要额外的存储权限**

## 构建

```bash
cd edge-shot
JAVA_HOME="<JDK 21 路径>" ./gradlew.bat assembleDebug
# 产物：app/build/outputs/apk/debug/app-debug.apk
```

- AGP 8.7.2 / Gradle 8.11.1 / compileSdk 35 / minSdk 23
- 版本号在 `app/build.gradle` 里改（`versionName` + `versionCode`）
